# Sanitized Case Summary

This public repository is based on a sanitized academic management accounting case. It does not include the original submitted PDF, professor details, roll numbers, group member details, or private academic front matter.

## Case Theme
Budgetary control, variance analysis, and Activity-Based Costing in a large FMCG-style operating environment.

## Central Dilemma
Should the firm retain its traditional costing and budgetary control system, partially integrate Activity-Based Costing with flexible budgets, or implement a full integrated performance management system?

## Public Version
This repository focuses only on:
- structured datasets,
- Python-based calculations,
- interactive dashboard logic,
- managerial insights,
- portfolio-safe project storytelling.
